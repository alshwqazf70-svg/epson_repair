# دليل النسخ الاحتياطي والاستعادة والتصدير

النسخة الاحتياطية تحمل **كل ما يخصك**: قاعدة البيانات (المقالات، التصنيفات،
سجلات الصيانة، الملاحظات، المراجع، سجل النشاطات) وكل الملفات والصور المرفوعة.

---

## 1. إنشاء نسخة احتياطية (من داخل التطبيق)

1. سجّل الدخول، ثم افتح `/admin/backups`.
2. اضغط **«إنشاء نسخة احتياطية الآن»**.
3. يظهر الملف في قائمة «النسخ الموجودة» باسم مثل:
   `backup-20250101-120000.zip`
4. اضغط **تنزيل** واحتفظ بالملف خارج الخادم (قرص خارجي/سحابة خاصة).

الملفات تُحفظ أيضاً على الخادم في:
```
<مجلد المشروع>/data/backups/
```

### ماذا يحتوي الأرشيف؟
```
backup-<تاريخ>-<وقت>.zip
├── data/                    ← قاعدة البيانات (epson_repair_master.db)
├── private_uploads/         ← كل الصور والمرفقات المرفوعة
└── backup_meta.json        ← تاريخ الإنشاء واسم قاعدة البيانات
```

---

## 2. الاستعادة (من داخل التطبيق)

> ⚠️ الاستعادة **تستبدل** قاعدة البيانات الحالية والملفات المرفوعة.

1. `/admin/backups` ← قسم «الاستعادة من ملف» ← اختر ملف `backup-*.zip` ← **استعادة**.
2. بعد اكتمال الاستعادة **أعد تحميل التطبيق**:
   - على PythonAnywhere: زر **Reload** في تبويب Web.
   - محلياً: أوقف الخادم (Ctrl+C) وأعد تشغيله.
3. سجّل الدخول من جديد (الجلسات القديمة لا تعمل بعد استعادة قاعدة البيانات).

**لماذا إعادة التحميل ضرورية؟**
عملية الويب تحتفظ باتصال مفتوح مع قاعدة البيانات، ولا ترى الملف المستبدل
إلا بعد إعادة تشغيل العملية.

---

## 3. نسخ واستعادة يدوياً (عبر سطر الأوامر)

### نسخ
```bash
cd ~/epson_repair_master
zip -r ~/epson-backup-$(date +%F-%H%M).zip data/epson_repair_master.db private_uploads
```

### استعادة
```bash
cd ~/epson_repair_master
# أوقف التطبيق أولاً (Reload/إيقاف الخادم)
unzip -o ~/epson-backup-2025-01-01-1200.zip -d ~/epson_repair_master_restore_tmp
cp ~/epson_repair_master_restore_tmp/data/epson_repair_master.db data/
cp -r ~/epson_repair_master_restore_tmp/private_uploads/. private_uploads/
# ثم أعد تشغيل التطبيق
```

## 4. التصدير بصيغة JSON (للأرشفة أو النقل)

- من `/admin/export` (أو زر «تصدير JSON» في لوحة الإدارة).
- الملف: `epson_repair_master_export_<التاريخ>.json`
- يحتوي: الموديلات، التصنيفات، كل مقالات الأعطال بحقولها العشرين،
  سجلات الصيانة، والملاحظات.
- **لا يحتوي** كلمات مرور ولا ملفات الصور نفسها (الصور تأتي في النسخة الاحتياطية ZIP).

> التصدير JSON مفيد للقراءة والأرشفة، أما الاستعادة الكاملة فتتم عبر ZIP.

---

## 5. جدول نسخ مقترح

| متى | ماذا |
|---|---|
| قبل أي تعديل كبير على المحتوى | نسخة احتياطية كاملة |
| قبل الاستعادة من نسخة قديمة | نسخة من الوضع الحالي أولاً |
| أسبوعياً (استخدام نشط) | نسخة + تنزيلها خارج الخادم |
| قبل ترقية Python أو المتطلبات | نسخة كاملة |

---

## 6. الأمان والخصوصية

- النسخة الاحتياطية تحتوي **كل بياناتك الخاصة** — لا تشاركها ولا ترفعها على خدمة عامة.
- التنزيل والتحميل محميان بالجلسة: لا يمكن لزائر مجهول تنزيل نسخة أو رفع ملف استعادة.
- أسماء الملفات تُتحقق على الخادم، ولا يُقبل أي مسار خارج مجلد النسخ (Path Traversal ممنوع).
- لا تُخزَّن كلمات المرور في سجل النشاطات ولا في التصدير.

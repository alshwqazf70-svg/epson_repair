# موسوعة إبسون الاحترافية لتشخيص أعطال الطابعات وصيانتها

**EPSON REPAIR MASTER — ULTIMATE PRIVATE REPAIR ENCYCLOPEDIA**

تطبيق ويب **خاص** (ليس موقعاً عاماً) لتشخيص أعطال طابعات إبسون النقطية وصيانتها،
بواجهة عربية كاملة RTL، يعمل محلياً أو على PythonAnywhere، من غير أي خدمة خارجية مدفوعة
ولا اتصال بالإنترنت لتشغيل التشخيص.

> ⚠️ **تنبيه مهم قبل القراءة**
> هذا المشروع **مرجع إرشادي** لا يغطي كل أعطال العالم، ولا يُغني عن دليل الخدمة الرسمي
> ولا عن فني مؤهل. كل ما لم نجد له مصدراً موثوقاً موسوم بـ«يحتاج إلى تحقق»،
> ولا يوجّهك المشروع إلى شراء أو استبدال قطعة قبل أن تُبرّر الفحوصات ذلك.

## 2. المتطلبات

- Python **3.10 أو أحدث** (مُختبر على 3.11)
- pip + بيئة افتراضية (مُوصى بها)
- لا حاجة إلى Docker، ولا إلى قاعدة بيانات خارجية (SQLite مدمج)

## 3. التشغيل على جهازك (خطوات فعلية)

```bash
cd epson_repair_master
python3 -m venv venv
source venv/bin/activate          # على Windows: venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env              # ثم عدّل SECRET_KEY بقيمة عشوائية طويلة
python3 -c "import secrets; print(secrets.token_hex(32))"

# إنشاء حساب المالك (لا توجد كلمة مرور افتراضية معروفة، ولا تسجيل عام)
python3 run_local.py --create-admin

# تهيئة قاعدة البيانات وتحميل المحتوى التأسيسي
python3 run_local.py --init

# التشغيل
python3 run_local.py --port 8000
# ثم افتح: http://127.0.0.1:8000
```

أو باستخدام أوامر Flask:

```bash
export FLASK_APP=wsgi.py
flask init-db        # تهيئة + محتوى تأسيسي
flask seed-db        # إعادة تحميل المحتوى التأسيسي (يحدّث ولا يكرّر)
flask run
```

## 4. إنشاء حساب المالك

لا يوجد حساب افتراضي ولا تسجيل عام بأي حال. الطرق المتاحة:

1. **تفاعلي (الأسهل):** `python3 run_local.py --create-admin`
   يطلب اسم مستخدم وكلمة مرور (10 أحرف على الأقل، تُكتب بصمت عبر `getpass`).
2. **غير تفاعلي (للأتمتة):**
   ```bash
   python3 tools/hash_password.py "كلمة-المرور-الخاصة-بك"
   # انسخ الهاش ثم:
   ADMIN_USERNAME=your-name ADMIN_PASSWORD_HASH=pbkdf2:sha256:... python3 tools/create_admin.py
   ```

كلمات المرور تُخزّن مجزّأة بخوارزمية `pbkdf2:sha256` مع ملح عشوائي (Werkzeug)،
ولا تُسجَّل في سجل النشاطات إطلاقاً.

## 7. قالب العطل الإلزامي (20 حقلاً)

كل مقالة عطل تعرض الحقول الآتية (ونموذج الإدارة يفرضها):

1. اسم العطل بالعربية
2. الاسم الفني بالإنجليزية
3. الموديل
4. رمز العطل أو المؤشر — أو «لا يوجد رمز موثق»
5. الأعراض كما يلاحظها المستخدم
6. درجة الخطورة (منخفضة/متوسطة/مرتفعة/خطر كهربائي)
7. الأسباب المحتملة **مرتبة حسب الاحتمال**
8. القطعة أو المنطقة المشتبهة
9. رقم القطعة — **فقط إن وُجد مصدر**
10. الأدوات المطلوبة
11. فحوصات أولية بسيطة وآمنة
12. شجرة تشخيص متدرجة
13. خطوات الإصلاح التفصيلية
14. طريقة التحقق من نجاح الإصلاح
15. اختبار نهائي بعد الإصلاح
16. أخطاء شائعة يجب تجنبها
17. متى تتوقف وتطلب فنياً مختصاً
18. الصور والمخططات (أو «الصورة الفنية لهذا الجزء غير متاحة بعد»)
19. المصدر والمرجع
20. تاريخ آخر مراجعة + مستوى الثقة

ويُضاف حقل **«مصدر فني مطلوب»** لكل مقالة لم يتحقق مصدرها.

**الفصل بين اليقين والاحتمال:** الأسباب تُعرض كاحتمالات مرتّبة تقديرياً،
ولا تُعرض كحقائق. نسبة الثقة في معالج التشخيص **تقدير إرشادي**
محسوب محلياً بقواعد صريحة، وسقفها الأقصى 92% (لا ندّعي اليقين).

## 8. معالج التشخيص

- يعمل **محلياً بالكامل**: موديل ← أعراض ← أسئلة متفرّعة ← أسباب مرتّبة ←
  فحوصات آمنة ← روابط لصفحات الإصلاح.
- **لا يوجد أي اتصال بخدمة ذكاء اصطناعي أو API مدفوع.**
- القواعد صريحة وقابلة للمراجعة: جدول أوزان `fault_symptoms`
  وخريطة أوزان لكل خيار إجابة (`question_options.weight_map`).
- النتيجة تُصفّى حسب الموديل المختار، وتُظهر درجة ثقة تقديرية مع تحذير «إرشادي».
- أداة **مقارنة الأعراض** تعرض الأعطال المتشابهة والفحص الذي يميّز بينها.

## 9. لوحة الإدارة (خاصة ومحمية)

`/admin` — لا يمكن الوصول إليها إلا بجلسة صالحة، والحماية على مستوى الخادم
(ليست مجرد إخفاء أزرار).

- إنشاء/تعديل/حذف: الأعطال، التصنيفات، الموديلات، المراجع، الملاحظات، سجلات الصيانة
- رفع الصور والمخططات الخاصة بك
- سجل نشاطات كامل (بدون كلمات مرور)
- بحث سريع، وإحصاءات، وتصدير JSON
- نسخ احتياطي واستعادة
- تغيير كلمة المرور
- طباعة أي مقالة أو أي سجل صيانة

## 10. سجل الصيانة

لكل عملية: الموديل، التاريخ، الأعراض، التشخيص الأولي، الاختبارات،
القطع المنظّفة، القطع المبدّلة، الإصلاح، النتيجة، صور قبل/بعد، ملاحظات.
قابل للبحث والتصفية والطباعة والتصدير، وهو **خاص تماماً** ولا يظهر للزوار.

## 11. الأمان (مطبّق فعلياً ومُختبر)

| البند | التنفيذ |
|---|---|
| تسجيل الدخول | إلزامي للوصول إلى أي مسار `/admin` أو ملف خاص |
| كلمات المرور | `pbkdf2:sha256` + ملح، ولا حساب افتراضي معروف |
| تحديد المحاولات | قفل مؤقت بعد 5 محاولات فاشلة (10 دقائق) |
| CSRF | Flask-WTF على كل طلب POST/PUT/DELETE |
| الجلسة | كوكي `HttpOnly` + `SameSite`، و`Secure` في الإنتاج |
| الحقن | استعلامات مُعَلْمَنة عبر SQLAlchemy (ORM) |
| XSS | ترميز المخرجات + CSP صارمة |
| Path Traversal | التحقق من بقاء المسار داخل مجلد الرفع |
| الرفع | التحقق من التوقيع الثنائي للصورة + الامتداد + الحجم + اسم فريد |
| الملفات الخاصة | خارج `static`، ولا تُقدَّم إلا بعد التحقق من الجلسة |
| الأخطاء | صفحات 403/404/413/500 موحّدة بلا تفاصيل تقنية |
| الأسرار | من متغيرات البيئة فقط، و`.env` مستثنى من Git |

## 13. النسخ الاحتياطي والاستعادة

- من لوحة الإدارة: `/admin/backups` ← «إنشاء نسخة احتياطية»
- النسخة ملف ZIP يحتوي قاعدة البيانات + مجلد `private_uploads`
- التنزيل والتحميل محميان بالجلسة
- الاستعادة: ارفع ملف ZIP من نفس الصفحة، ثم **أعد تحميل التطبيق**
  (زر Reload في PythonAnywhere) حتى تُقرأ قاعدة البيانات المستعادة
- التفاصيل في [docs/BACKUP_RESTORE_AR.md](docs/BACKUP_RESTORE_AR.md)

## 15. سياسة المحتوى والصور

- لا نخترع أرقام قطع، ولا قيماً كهربائية، ولا إجراءات معايرة، ولا أرقام صفحات.
- الرسوم المرفقة (`static/images/diagrams/*.svg`) **رسوم توضيحية مرسومة داخلياً**
  وموسومة بعبارة: **«رسم توضيحي غير مطابق بالضرورة للبنية الداخلية الدقيقة»**.
- لا تُعرض صورة طراز آخر على أنها الطراز المطلوب، ولا تُستخدم صور مولّدة بالذكاء
  الاصطناعي كأنها صور خدمة حقيقية.
- عند غياب الصورة يظهر: **«الصورة الفنية لهذا الجزء غير متاحة بعد»**.
- يمكنك رفع صورك الخاصة من لوحة الإدارة، شرط احترام حقوق النشر.
- الصور المرفوعة تُعرض فقط لصاحب الحساب بعد تسجيل الدخول.

## 16. السلامة

- تحذير «افصل الطاقة قبل أي خطوة داخلية» في أعلى كل مقالة.
- فصل واضح بين ما يُسمح للمستخدم به وما يخص الفني فقط.
- لا إجراء لقياسات على دوائر حيّة، ولا تزييت إلا إن نصّ الدليل عليه.
- زر/تنبيه صريح: **«أوقف التشغيل وراجع فنياً مؤهلاً»** في المقالات عالية الخطورة.

## 17. ما لا يدّعيه المشروع

- لا يدّعي تغطية كل أعطال إبسون أو كل الطرازات.
- لا يدّعي أن نتائجه تشخيص مؤكد بنسبة 100%.
- لا يوفّر مخططات خدمة رسمية كاملة (غير متاحة قانونياً للنشر هنا).
- لا يحتوي وثائق مسرّبة أو محتوى محمي بحقوق نشر.

## 18. الترخيص والاستخدام

مشروع خاص بك للاستخدام الشخصي/الداخلي. الشيفرة مفتوحة لك لتعديلها،
أما محتوى المقالات فمرجع إرشادي، ولا يجوز نشره كدليل خدمة رسمي،
ولا تحميل المشروع مسؤولية أي ضرر ناتج عن صيانة غير مؤهلة.
